LECTURE 00

Why this project started, and what it turned into

Every research project has a premise. This one's premise was wrong in an interesting way, and the interesting part is why.

The original idea

A reconfigurable intelligent surface (RIS) is a flat panel of many small reflecting elements. Each element can shift the phase of the wave that bounces off it. Set all the phases correctly and the reflections add up in step at the receiver; set them randomly and they cancel. A 1024-element surface has 1024 knobs to turn, and they must be re-turned every time the channel changes — on the order of every millisecond.

The original reasoning went like this:

  1. To set the knobs you need channel state information (CSI) — you need to know what the wave is doing at each element.
  2. Collecting all that CSI at one central controller is expensive and does not scale.
  3. Large surfaces are built from tiles, each with its own local controller.
  4. Therefore: treat each tile as a federated-learning client. Train one shared neural phase predictor across the tiles, exchange only model updates over an on-chip network, and never move raw CSI.

That was Fed-RIS. It has the shape of a good idea. Steps 1–3 are true. Step 4 is where it fails, and finding out exactly why is what this project became.

The through-line

Federated learning exists to share information between coupled sub-problems. If the sub-problems are independent, federation has nothing to do. Lecture 02 proves the independence. Lecture 04 finds where coupling genuinely reappears — and that is where the real project lives.

LECTURE 01

The physics, from one element to a thousand

Everything in this project is a consequence of one equation. This lecture builds it from scratch and then shows the exact code that implements it.

One element

A wave leaves the base station (BS), hits element n of the surface, and continues to the user. Two hops. Call the first hop's complex gain hn and the second gn. The element itself multiplies by a unit-magnitude phase shift e jθn — it cannot amplify, only rotate.

Cascaded coefficient cn = gn · hn

One complex number per element, combining both hops. In this project |c| ≈ 10−10 — mmWave two-hop path loss is brutal, and this tiny scale causes real numerical problems later.

The whole surface

The receiver does not see elements separately. It sees one summed wave: the blocked direct path plus every reflection, all superposed.

Governing equation — everything follows from this heff(θ) = hd + Σt=1..T Σn=1..Nt ct,n e jθt,n γ(θ) = ρ · |heff(θ)|2,    ρ = Pt / σ2

hd direct BS→user path (blocked by 30 dB) · T=16 tiles · Nt=64 elements each · γ received SNR · ρ transmit-to-noise ratio before propagation, 120 dB at Pt=30 dBm and σ2=−90 dBm.

A naming trap worth avoiding

ρ is not an SNR anyone measures. It is transmit power over noise power with no path loss in it, which is why it reaches 120 dB. Received SNR γ is what the receiver experiences — around 13–28 dB here. The original paper plotted against ρ on an 88–142 dB axis, which reads as nonsense to a wireless reader. The corrected work plots Pt in dBm.

Why the gain grows as N²

Suppose the direct path is fully blocked and every element has the same magnitude |c|. Align all phases so the terms add in step. Then the amplitudes add linearly:

Coherent array gain |heff| = N|c|   ⇒   γ = ρ N2|c|2 doubling N → +6.02 dB   ·   64 → 1024 elements → 20 log10(16) = 24.08 dB

Power grows as N², not N, because the surface is coherent: it aligns phases, it does not merely collect more energy. This N² law is the single most important sanity check in the project — Lecture 03 uses it to catch a major bug.

The propagation model as implemented

These are the actual formulas in src/surface_channel.py. Each is a modelling choice with a consequence.

Close-in path loss, reference distance 1 m PL(d) = (λ / 4π)2 · d−α

Free-space at 1 m, then decaying with exponent α. Here α=2.5 on each reflecting hop, α=3.5 on the direct link, plus 30 dB of extra blockage loss on the direct path.

Line-of-sight component — spherical, not planar hLoSn = √PL(dn) · e −j k dn,    k = 2π/λ

dn is the exact distance to element n, computed per element. This matters: the Fraunhofer distance of this aperture is 2D2/λ ≈ 11 m, and users sit inside a 10 m room. A flat-wavefront approximation would be wrong at these ranges.

Non-line-of-sight — 5 plane waves shared across the aperture hNLoS(r) = Σp=1..5 gp · e j k (dp · r),    gp ~ CN(0, e−p)

dp are random unit directions in the half-space in front of the panel; r is element position relative to the aperture centre. Because every element is evaluated against the same five scatterers, spatial correlation emerges from real geometry rather than being imposed by a correlation matrix.

Rician mixing and element aperture gain h = √(K/(K+1)) · hLoS  +  √(1/(K+1)) · hNLoS,    K = 10 dB Ge = 4πAe/λ2 = 4π(λ/2)2/λ2 = π  (per hop)

K=10 dB means the deterministic LoS component carries ~91% of the power. The cascade is then c = Ge2 · hBS→n · hn→user, applying the aperture factor once per hop.

Why the old model was replaced

The legacy generator multiplied the entire channel — LoS included — by a Cholesky factor of a correlation matrix. That scrambles the deterministic spherical wavefront, which is precisely the structure a phase-aligning surface depends on. The rewrite generates the field over the whole aperture first, then slices it into tiles, so tiles see the same scatterers by construction and their contributions add coherently.

LECTURE 02

Separability: the result that reshaped the project

This is the most important lecture. It is three lines of mathematics that invalidate the original thesis, and understanding it properly is what lets you see where the real problem is.

The optimization problem

What we want maxθ ∈ [0,2π)N   log2(1 + ρ|heff(θ)|2)

log is monotone in its argument, so maximizing rate is identical to maximizing |heff|2, which is identical to maximizing |heff|. One thousand and twenty-four coupled variables — apparently.

The three lines

Apply the triangle inequality to the sum. For any complex numbers, the magnitude of a sum is at most the sum of magnitudes:

Upper bound |heff| = |hd + Σ cn e jθn|  ≤  |hd| + Σ |cn e jθn| = |hd| + Σ |cn|

Note |cnejθ| = |cn|: the phase shifter cannot change magnitude, so the bound does not depend on θ at all.

Equality in the triangle inequality holds exactly when every term points in the same direction in the complex plane. Choose the direction of hd:

The optimum — achieved, not approached θ★n = ∠hd − ∠cn ⇒   |heff| = |hd| + Σ|cn|   (the bound is attained)

This is maximal-ratio combining (MRC). It is closed form, it costs one atan2 per element, and it is exactly optimal — not a relaxation, not an approximation.

The consequence

Look at what θ★n depends on: cn and nothing else, plus one global scalar ∠hd shared by everyone. Element 900's optimal phase does not depend on element 12's channel. There is no coupling between elements, therefore no coupling between tiles, therefore nothing for a federated algorithm to share.

Each tile can compute the exact global optimum using only its own 64 coefficients. No training. No model exchange. No rounds. No network.

The FFT analogy — and where it breaks

It is worth contrasting this with a decomposition that does buy you something, because the difference is the whole point.

In a radix-2 decimation-in-time FFT, you split an N-point DFT by parity of the input index:

Radix-2 DIT decomposition X[k] = Σn even x[n]WNnk  +  WNk Σn odd x[n]WNnk  =  E[k] + WNkO[k] WN = e−j2π/N,    O(N2) → O(N log N)

The twiddle factor WNnk factorizes, so the problem splits into two half-size transforms. But the outputs are still coupled: you must recombine E[k] and O[k] through the butterfly X[k]=E+WkO, X[k+N/2]=E−WkO. The recombination stage is mandatory — it is where the coupling lives.

The FFT is a clever factorization of genuine coupling: every output depends on every input, and the algorithm reorganizes that dependency into log N cheap stages. The saving is computational; the answer is unchanged.

The SISO RIS problem has no such structure to exploit, because there is no coupling to begin with. There is no butterfly stage, because there is nothing to recombine. The decomposition is not a clever algorithm; it is the trivial observation that N independent scalar problems are N independent scalar problems.

What this kills

Federation transfers information between clients whose sub-problems interact. Here they do not interact. So "federating the tiles of one surface" is not a hard problem solved well — it is a non-problem, and any learned approximation can at best tie the closed form while costing training, traffic, and accuracy.

The measurements confirm it exactly. In the supplied-CSI experiment, local MRC and the perfect-CSI oracle agree to 0.00 dB (both −92.33 ± 0.31), and both match iterative gradient ascent to within 0.02 dB.

Where coupling genuinely reappears

Two escapes exist, and only one of them is cheap:

  • Multiple users. With interference, raising user A's signal can lower user B's. The objective stops being separable and joint design becomes real. This is a substantial redesign.
  • Incomplete observation. If you cannot measure cn directly — only a few mixtures of all the c's at once — then your estimate of any one coefficient depends on all the measurements jointly. The optimization is still separable; the inference is not.

The project took the second route. That is Lecture 04.

LECTURE 03

The geometry bug, and how the N² law exposed it

A worked example of using physics as a unit test. The bug was invisible in the code and glaring in the results, once you knew what to look for.

The symptom

In the original results, activating more elements stopped helping. Between 512 and 1024 elements the oracle gained only 1.3 dB where theory predicts 6 dB. The paper explained this as a physical "deployment effect" — peripheral tiles seeing weaker channels — and presented it as a finding about tile placement.

The diagnosis

Back out the per-element cascaded amplitude from the reported SNRs. If the surface is uniform, every element should contribute about equally:

A 21 dB spread in per-element channel power. On a panel 17 cm across, at ranges of several metres, that is physically impossible — every element is essentially the same distance from everything. The only way to get a 21 dB spread is if the elements are not on one panel.

They were not. tile_positions_for() placed the 16 tiles on a circle of radius 10/3 m around the room centre:

The legacy tile layout xi = 5 + (10/3)·cos(2πi/16),   yi = 5 + (10/3)·sin(2πi/16),   zi = 1.5 pairwise separation: 1.30 m … 6.67 m   vs   true panel diameter 0.1714 m

A 39× discrepancy between the simulated object and the described object. The "surface" was sixteen separate panels scattered around a room, each with its own independent scatterers.

The second error, layered on top

The "ideal N² law" reference curve was anchored at the N=64 point, which was direct-path dominated — 64 elements added only 0.45 dB over no surface at all. Extrapolating +20log10(N/64) from a point where the surface contributes almost nothing produces a reference that no design could ever meet. The apparent 10 dB shortfall of even the oracle was an artifact of the reference, not of any phase design.

The fix and the verification

src/surface_channel.py generates one contiguous 32×32 uniform planar array at λ/2 pitch, computes the full field, then slices it into tiles. The N² reference is re-anchored on reflected-only power with the direct path excluded.

Measured 23.99 dB against a theoretical 24.08 dB — a 0.09 dB discrepancy over a 16× increase in aperture. The saturation is gone. Tile-average channel power now spreads by 0.06–0.18 dB across the surface, down from 21.4 dB.

Note also that local MRC and the oracle are identical at every aperture size. That is Lecture 02's separability showing up as a measurement.

The transferable lesson

The N² law is a closed-form consequence of coherent addition. Any simulator that violates it is broken, and the size of the violation tells you how. This is why the corrected repository pins physical laws in test_tier01.py — aperture contiguity, spherical LoS phases, the reflected-only anchor — rather than trusting the outputs to look reasonable.

LECTURE 04

Acquisition: the problem that is actually hard

A passive surface cannot measure anything. Once you take that seriously, a genuine inference problem appears — and this is where the project found its real question.

The physical constraint

A reflecting element is a patch of metal with a tunable impedance. It has no low-noise amplifier, no mixer, no analogue-to-digital converter — because adding 1024 receive chains would make it an antenna array, not a cheap passive surface. The entire commercial argument for RIS is that the elements are nearly free.

So the original claim that "each tile estimates its own CSI slice from pilots" was not merely unproven; it was impossible for the hardware described.

What can actually be measured

The receiver has a receive chain. So the surface cycles through M known probing configurations while the transmitter sends a pilot, and the receiver reports one complex number per configuration.

Observation model — the whole basis of the experiment ym = hd + Σn=1..N cn e jφm,n + wm,    wm ~ CN(0, 1/ρ)

φm,n is the known probe codebook (fixed, seeded 2024, random uniform — every probe illuminates every element, so each measurement carries information about the whole channel).

Stack it and the structure becomes obvious:

Linear inverse problem y = A x + w,    x = [hd, c1, …, cN]T ∈ ℂN+1 Am,: = [1, e jφm,1, …, e jφm,N]  ∈ ℂM×(N+1)

The leading column of ones accounts for the direct path, which is present in every probe regardless of configuration.

Where the difficulty lives

N+1 = 1025 complex unknowns. The experiments use M = 16 and M = 64 measurements.

When M < N+1, A has a nontrivial nullspace: infinitely many channel vectors explain the same measurements exactly. No estimator can resolve them without extra assumptions. This is not a noise problem — it is a rank problem, and it persists at infinite SNR.

This is the legitimate opening for a learned prior. A model trained across many scenes might learn which channel vectors are physically plausible and pick sensibly within the nullspace. That is the project's real research question, and unlike the original one, it is well posed.

Training labels are not free either

A learner needs targets. Where do they come from? Not from simulator truth — that would be cheating. The corrected design acquires them the same way anything else would: with a full orthogonal DFT probe sequence of N+1 = 1025 probes per training scene.

Training-data acquisition cost, charged explicitly pilot symbols = (S + V) · (M + N + 1) = (600 + 200) · (16 + 1025) = 832,800 symbols per tile-set

S=600 training scenes, V=200 validation scenes. Labels are noisy least-squares estimates at the training SNR, with per-coefficient variance 1/[ρ(N+1)] — not ground truth.

Charging for pilots in the metric

Spending symbols on probing means not spending them on data. A scheme that uses 1025 probes out of a 2048-symbol coherence block has only half the block left. The headline metric accounts for this:

Pilot-adjusted net spectral efficiency Rnet = max{0, 1 − Mused/L} · 𝔼[log2(1 + γ)],    L = 2048

This is what makes the comparison fair: full-probe LS achieves a far better channel estimate but pays 50% overhead for it, so it does not automatically win. Feedback latency, feedback errors and training amortization are not included — stated explicitly as a limitation.

LECTURE 05

The estimators, and why each one is in the comparison

A negative result is only as strong as the baselines it loses to. Each of these exists to close off a specific "but did you try…" objection.

Best observed probe

Look at the M reported responses, find the largest, and simply re-apply that configuration. No channel model, no estimation, no training.

Selection rule θ = φm★,    m★ = arg maxm |ym|

The classical low-overhead baseline. Feedback cost: one integer index. It is the floor any sophisticated method must clear — and, as it turns out, a floor the neural models do not clear.

LMMSE followed by MRC

The strongest linear estimator at the same pilot budget. It learns the channel's second-order statistics from the same training scenes the neural models see, pooled centrally.

Linear minimum mean-square-error estimate x̂ = μ + R AH(A R AH + ρ−1I)−1(y − Aμ) R = 𝔼[(x−μ)(x−μ)H]  estimated from S training scenes, with diagonal loading

Then apply MRC to x̂. This is the key control: it is exactly the "use a learned prior to resolve the nullspace" strategy, executed optimally within the linear class. If a neural network cannot beat it, the network is not adding anything a covariance matrix does not already capture.

An implementation detail that matters

With samples stored as rows, the covariance must be xc.T @ xc.conj(), not xc.conj().T @ xc. The latter conjugates R and reverses every spatial phase — producing a beam pointed the wrong way. A sign error of this kind is invisible in the code and catastrophic in the results, which is why test_tier01.py pins the covariance orientation.

Local linear estimator followed by MRC

The decisive baseline for the federation question. Each tile independently fits a ridge regression from the shared receiver feedback to its own channel coefficients:

Per-tile ridge regression — no federation, no rounds Wt = (YHY/S + δI)−1 (YHXt/S),    δ = 10−3·tr(YHY/S)/M

Tile t needs only the M-dimensional feedback and its own (Nt+1) labels. No other tile's data, no model exchange, no aggregation rounds. If federation is worth anything, it must beat this.

Full-probe least squares

The high-acquisition-cost control: N+1 orthogonal DFT probes give a well-conditioned system and per-coefficient error variance 1/[ρ(N+1)]. Excellent channel estimate, 50% pilot overhead. Included to show what buying your way out of the rank deficiency actually costs.

Perfect-CSI oracle

Unattainable by construction — it reads the true channel. Present as a ceiling, and explicitly excluded from the deployable comparison because its acquisition cost is zero only because it cheats.

LECTURE 06

The learning setup, and the discipline around it

Most of the engineering effort here went not into the model but into making sure the comparison could not flatter it.

What the network sees

Inputs are the M complex probe responses plus normalized tile coordinates — nothing else. Specifically not: receiver position, per-element test CSI, or the true direct-path phase. The responses are rotated by −∠y1 and RMS-normalized, which removes a common channel rotation the optimal phases are invariant to. Output phases are absolute; no oracle offset is added afterwards. test_tier01.py pins all of this.

The objective

Not mean-squared error against MRC labels. Two phase vectors with identical MSE can deliver wildly different SNR, because what matters is whether the summed paths are coherent. So the loss is the achieved rate, normalized by the best rate achievable on that batch:

Genie-normalized rate loss — exactly as implemented ℒ = mean [ 1 − log(1 + ρ|hd + Σ cne jθn|2) / log(1 + ρ(|hd| + Σ|cn|)2) ] θn = atan2(v̂n, ûn)   from a (cos, sin) output pair

The denominator is the MRC bound from Lecture 02 — the loss is "fraction of achievable rate you are leaving on the table", so it sits in [0,1] regardless of absolute path loss.

Two design choices worth understanding:

  • Why normalize? At these path losses ρ|heff|2 << 1 early in training. An unnormalized rate sits near zero with vanishing gradients. Dividing by the genie rate keeps the loss O(1).
  • Why a (cos, sin) head? Regressing an angle directly has a discontinuity at 0/2π: two phases that are physically 1° apart can be 359° apart numerically. Predicting a point on the unit circle and recovering the angle with atan2 removes the wrap-around entirely.

Federated averaging

FedAvg wr+1 = Σt=1..T (nt/n) · wtr

Each tile starts from the global weights, runs local steps, and the results are averaged by sample count. Rounds run 27–123 with validation-based early stopping (patience 15, min-delta 10−4, minimum 20 rounds, cap extended 100→300 when exhausted).

The control that makes it a fair fight

The original comparison was confounded: the centralized model ran ~16× more optimizer steps than each federated client, and the paper described the difference as being only about data locality. The corrected harness records and matches the budgets explicitly:

Experimental protocol

600 training / 200 validation / 600 test scenes per seed. Five independent seeds (42, 123, 456, 789, 1024). Every controller scored on the same true held-out channels within a seed. Confidence intervals are Student-t over seeds; paired differences use matched seeds. Validation selects checkpoints without ever consulting test scores.

LECTURE 08

The interconnect model, and the discipline of not over-claiming

This part of the project was rebuilt twice. It is a good case study in the difference between a calculation and a measurement.

What was wrong originally

  • Links were modelled at 10 Gb/s — an off-chip SerDes figure, roughly 20× too slow for an on-chip network. Every latency was inflated accordingly, which is what made the headline speedups look impressive.
  • Energy used hardcoded constants (0.98 pJ/flit/router, 0.37 pJ/flit/link) with no technology node behind them.
  • The text attributed latency reductions to network diameter, but the model computes bottleneck serialization — five of six topologies returned identical latency despite diameters of 4 and 8.
  • The topology labelled "Butterfly" was actually an XOR hypercube.

The corrected estimator

Per-phase latency t̂q = max{ maxe Le,q/B,   maxv Iv,q/Bep,   maxv Ev,q/Bep }  +  Hq(clink + crouter)/f

Le,q directed-link load · I, E endpoint injection/ejection loads · B link rate · Hq longest route · f clock. Serialization and traversal are reported separately. Transfers round up to whole 16-byte flits. Sequential phases add.

Link rate is now 128 bits/cycle at 1 GHz (128 Gb/s), with a 2 GHz variant. These are declared assumptions, not synthesis results. Energy is reported as null, because no calibrated circuit exists to support a number.

The finding, stated correctly

Under a parameter server, all seven topologies cost 5.645 ms to four decimal places, because the bottleneck is the server's own endpoint port — the network is irrelevant. Diameter does not predict latency: Ring (diameter 8) is the fastest ring-all-reduce and Hypercube (diameter 4) is nearly the slowest.

The protocol matters, the topology mostly does not. That is the opposite of the original paper's claim, and it falls out of the corrected accounting rather than being asserted.

What is explicitly not claimed

No RTL, no synthesis, no area, no technology node, no cycle-accurate validation, no Noxim cross-check. Buffers, credit stalls, arbitration, packet headers and physical wire delay are all absent. These are conditional estimates under stated assumptions — not bounds, not traces, not measured training durations. And a 17 cm RF aperture is not asserted to be one silicon die.

LECTURE 09

Novelty, built from the ground up

You said previous explanations of novelty were unclear. So this starts from what a novelty claim is, then applies the test to every claim this project has made.

What makes something novel, operationally

A reviewer is not asking "is this new to you?" They are asking three questions, in order:

  1. Is it different from prior work? Not "has anyone written this exact sentence" but "does it require the field to know something it did not know."
  2. Is the difference load-bearing? If removing your contribution leaves the results unchanged, the difference is decorative.
  3. Is it demonstrated? A claim you did not measure is a hypothesis, not a contribution.

A claim must pass all three. The original paper's claims each failed a different one, which is instructive.

What is actually novel now

Three things. Each is stated so you can see which of the three tests it passes and how.

N1 — A negative result on federating a passive RIS

Different: the RIS-plus-federated-learning literature reports positive results. No one has published a controlled demonstration that federation is the wrong tool for this class of problem.
Load-bearing: it changes what a practitioner should build. The right answer is a closed form or a per-tile ridge regression, not a distributed training system.
Demonstrated: five seeds, two pilot budgets, four architectures, matched optimizer budgets, paired confidence intervals, and every control including training-free ones.

The strength here is not that federation lost. It is who it lost to: a scheme that reports one integer, and a per-tile regression fitted independently with no communication at all.

N2 — The separability argument as a design boundary

Different: MRC optimality for single-user RIS is textbook. What is not standard is using it as a screening test: before proposing any distributed or learned method, check whether the objective decomposes. If it does, the method cannot help.
Load-bearing: it explains the negative result mechanistically rather than empirically, and it predicts where the boundary moves — multi-user interference, or under-determined observation.
Demonstrated: local MRC equals the oracle to 0.00 dB at every aperture size and every error level.

N3 — An acquisition-honest benchmark

Different: most RIS learning papers assume CSI appears from somewhere. This one charges every pilot symbol: probing, training labels at 1025 DFT probes per scene, feedback, and model transfer — each accounted separately.
Load-bearing: it reverses conclusions. Full-probe LS has the best channel estimate but a 50% pilot cost, so it does not dominate on net rate. Without pilot accounting you would recommend the wrong scheme.
Demonstrated: the pilot-adjusted rate metric, the acquisition audit, and hash-manifested provenance on every table.

The honest one-paragraph version

This is not a paper about a method that works. It is a paper about a method that should work by analogy to other fields, does not, and about why not — with the mechanism identified (separability), the boundary mapped (where coupling reappears), and the accounting done properly enough that the negative result is trustworthy. That is a real contribution, and it is a different one from the paper that was originally written.

The one thing that could still sink it

A negative result must rule out incompetence as the explanation. Right now the learner's validation loss barely moves, and no experiment yet shows the pipeline can learn anything. Until it does, a reviewer can read the entire result as "your training was broken." One experiment fixes this. It is P2 below.
